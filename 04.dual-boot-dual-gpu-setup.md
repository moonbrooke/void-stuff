# Dual-Boot and Dual GPU (Intel+NVIDIA) Setup

## Dual-Boot Setup

1. Enable OS detection in `/etc/default/grub`: `sudo nvim /etc/default/grub`

2. Un-comment or append the following line: `GRUB_DISABLE_OS_PROBER=false`

3. Update the GRUB config: `sudo update-grub`

## Fix Dual-Boot Time Desync

1. Edit `rc.conf` file: `sudo nvim /etc/rc.conf`

2. Change or add the `HARDWARECLOCK` line to: `HARDWARECLOCK="localtime"`

3. Force an immediate hardware clock sync using `hwclock`: `sudo hwclock --systohc --localtime`

4. Enable Network Time Protocol (NTP) by installing `chrony`: `sudo xbps-install -S chrony`

5. Enable and start the `chronyd` service via runit:

```bash
sudo ln -s /etc/sv/chronyd /var/service/
sudo sv up chronyd
```

6. Check sync status: `chronyc tracking`

## Configure Kernel Parameters for DRM Modesetting

1. Open `/etc/default/grub`. Add: `nvidia-drm.modeset=1` to existing `GRUB_CMDLINE_LINUX_DEFAULT` line.

```bash
GRUB_CMDLINE_LINUX_DEFAULT="loglevel=4 nvidia-drm.modeset=1"
```

2. Regenerate GRUB with `sudo update-grub`

## Configure Initramfs (dracut)

1. Create `nvidia.conf` file: `sudo nvim /etc/dracut.conf.d/nvidia.conf`

2. Add the following line to load the required driver modules:

```base
add_drivers+=" nvidia nvidia_modeset nvidia_uvm nvidia_drm "
```

3. Regenerate kernel image with: `sudo dracut --force`

4. Configure Hyprland environment variables (Optional?)

```bash
# Force primary rendering to the Intel GPU, using NVIDIA only as secondary
# Find your device nodes with: ls -l /dev/dri/by-path
env = WLR_DRM_DEVICES,/dev/dri/card1:/dev/dri/card0

# Hardware acceleration and Wayland flags
env = LIBVA_DRIVER_NAME,nvidia
env = __GLX_VENDOR_LIBRARY_NAME,nvidia
env = NVD_BACKEND,direct
```

## Configure Power Management (Dynamic PM / RTD3) (Optional?)

1. Create a modprobe configuration file: `sudo nvim /etc/modprobe.d/nvidia-pm.conf`

2. Enable dynamic power management: `options nvidia NVreg_DynamicPowerManagement=0x02`

3. Reboot the system: `sudo reboot`
